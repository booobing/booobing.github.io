개인정보처리방침

시행일 2026년 11월 5일 · 운영자 booobing

마법의 책은 계정 없이 이용하는 사진 게임입니다. 현재 게임에서 사용하는 정보와 외부 서비스는 다음과 같습니다.

브라우저에 저장하는 정보

첫 펼치기 여부와 직전 사진 번호를 브라우저의 세션 저장소(sessionStorage)에 기록합니다. 버튼 안내와 동일 사진의 연속 추첨 방지에 사용하며 게임 코드가 이 정보를 별도의 서버로 전송하지 않습니다. 이름, 이메일, 위치 정보 또는 사용자의 사진을 입력받지 않습니다.

저장 정보는 브라우저의 해당 사이트 데이터 삭제 기능으로 지울 수 있습니다. 일반적으로 탭 세션이 끝나면 삭제되지만 브라우저의 세션 복원 설정에 따라 유지될 수 있습니다. 저장을 차단해도 게임은 열려 있는 페이지의 메모리로 작동합니다.

웹사이트 호스팅

이 사이트는 GitHub Pages를 통해 제공됩니다. 페이지와 사진을 요청할 때 호스팅 제공자가 IP 주소 등 접속 정보를 처리할 수 있습니다. 해당 서비스의 처리 내용은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

광고와 방문 분석

현재 Google 광고 스크립트, 보상형 광고 SDK, 방문 분석 도구를 불러오지 않습니다. 모든 펼치기는 무료이며 광고 시청이나 클릭을 요구하지 않습니다. 홈페이지에는 AdSense 사이트 계정 확인용 메타 태그만 사용합니다.

추후 광고를 도입할 때에는 사용하는 광고 제공자, 쿠키·식별자 처리, 맞춤 광고 선택 방법을 이 방침에 반영하고 필요한 동의 절차를 마련한 후 적용합니다. Google의 데이터 처리 방식은 Google 파트너 사이트에서의 데이터 사용 안내에서 확인할 수 있습니다.

사진 콘텐츠

게임의 사진은 AI로 제작한 가상의 성인과 장소입니다. 방문자의 카메라·사진첩에 접근하거나 사진을 업로드받지 않습니다. 사진의 사람 수는 미리 검수해 둔 값입니다.

문의와 변경 안내

운영자 booobing에게 문의하거나 오류를 신고하려면 게임 저장소의 GitHub 이슈를 이용해 주세요. 이슈는 공개되므로 이름, 연락처 등 개인정보를 적지 마세요. 이슈 작성 시 GitHub가 처리하는 정보에는 GitHub의 방침이 적용됩니다.

저장 정보나 외부 서비스가 바뀌면 이 페이지와 시행일을 갱신합니다.
