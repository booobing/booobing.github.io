description: Trigger when a task starts without an approved charter, touched-file list, or explicit non-goals. Do not use once execution is already bounded.
---

# Goal
작업 전에 짧은 charter를 만든다.

# Produce exactly
1. Objective
2. Non-goals
3. Touched files
4. Ambiguity: LOW / MEDIUM / HIGH
5. Difficulty: Simple / Medium / Complex
6. Required checkpoints
7. Rollback plan

# Rules
- 12줄 안팎으로 끝낸다.
- 구현 아이디어를 길게 쓰지 않는다.
- touched files는 가장 보수적으로 잡는다.
- HIGH ambiguity면 구현하지 않는다.
